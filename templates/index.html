HOW IT WORKS

Agentic RAG workflow

The UI visualises the trace returned by your backend for each completed request. The following is the intended workflow described by this project:

  1. Route questionDetermine how the request should be handled.
  2. Retrieve private knowledgeSearch the company knowledge base.
  3. Grade evidenceAssess whether retrieved context is useful.
  4. Web fallback if weakUse external evidence when the configured workflow requires it.
  5. Rewrite & retryImprove the query and retrieve again when needed.
  6. Grounded answerReturn the response with source metadata and citations.
